# Project-VOLNA

Lancer Main.py pour démarrer la simulation.

📖 Description

Ce projet a été réalisé dans le cadre du concours 'Les trophées NSI' 2026
Il consiste en une simulation interactive d’un réacteur nucléaire, permettant de comprendre les mécanismes fondamentaux de la production d’énergie nucléaire.

L’objectif est de modéliser le comportement d’un réacteur en fonction de différents paramètres (température, barres de contrôle, réaction en chaîne, etc.), tout en sensibilisant aux enjeux de sécurité.

🎯 Objectifs

Comprendre le fonctionnement d’un réacteur nucléaire
Permettre à l’utilisateur d’interagir avec le système


⚙️ Fonctionnalités

🔥 Simulation de la température du cœur
⚛️ Gestion des barres de contrôle
📈 Évolution de la réaction nucléaire en temps réel
🎮 Interface graphique interactive


🧠 Principe de fonctionnement

La puissance du réacteur va faire chauffer l'eau de la cuve,
cette eau va bouillir et faire monter la préssion du système,
la préssion va être utilisée pour faire tourner une turbine et produire de l'éléctricité,
(Il manque des systèmes ici),
l'eau retourne ensuite de le réacteur


🛠️ Technologies utilisées

Langage : Python
Bibliothèques : pygame, sys, math, statistics
Outils : VS Code, Github


🚀 Lancer le projet

Dans un terminal :
python main.py


🎮 Utilisation

Ajuster les barres de contrôle
Observer la température et la réaction
Maintenir le réacteur dans une zone stable (très compliqué car il n'y a pas d'assistance)
ouvrir la valve de contournement (40% à peu près)
quand la préssion dépasse 4000 vous pouvez ouvrir la valve principale
ajuster pour que la turbine tourne à 1500RPM
connecter au réseau
fermer la valve de contournement et ajuster la valve principale pour avoir une pression de 7100 hP
augmenter la puissance
augmenter l'ouverture de la valve principale pour maintenant la pression à 7100 hP


⚠️ Limites

Simulation simplifiée (ne représente pas un vrai réacteur)
Certains phénomènes physiques sont approximés
Interface basique
Le contrôle est très compliqué car il n'y a aucun système de sécurité
